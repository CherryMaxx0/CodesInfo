List is literary like an [[cpp_array|array]] in c++. It looks like this below: ^29f46a
```python
list = ["Cat","apple"]
list_numbers = [1,2,3,4]
```
Doesn't requires type, can be anything in one collectible place.
```python
print(list[0])
list[1]="Mango"
```
Can be accessed with index to modify or print it out.
And to make immutable, we have another type [[py_tuple|Tuple]], *<-go to the note to see more*

We can assign empty List, to be assign values later on.
```python
list=[]
list[0]=1
```
The index is set to 0 as default.
