Python is ==a popular, high-level programming language== known for its simple, readable syntax that looks like normal English. Has 3 most important use of python for:
- **Web Development:** Builds the back end of websites and apps using frameworks like Django and Flask.
- **Data Science and AI:** Powers machine learning, deep learning, and data analysis using tools like TensorFlow and pandas.
- **Automation:** Automates boring, repetitive tasks like moving files, parsing PDFs, or sorting spreadsheets

## Python Logics & Basics
### [[py_operator|Operators]]
It is a special symbol or keyword used to perform computations and operations on variables and value. That is said, to have different types of operator for different type of usages. 
*Get into the linked note to get more info about operators*.
### [[py_If-Else|If, Elif & Else]]
Basically means Conditional coding. Like, to run block of code when condition given is met.
### [[py_Loop|Loops]]
Loops basically means to go in circle, iterating same block of codes multiple times, as much as possible. There are mainly two types: 
- [[py_ForLoop|For Loop]]
- [[py_WhileLoop|While Loop]]
### [[py_list|List]]
A built-in, ordered collection of items enclosed generally in `[]` square brackets, which is mutable. It has 2 more types:
- [[py_tuple|Tuple]]
- [[py_set|Set]]
### [[py_function|Function]]
Defining a function using `def`, a data type identification keyword exclusively used for function defining.
### [[py_class|Class]]
Similarly as function, `class`  is the exact keyword for creating a class type. Keep in mind, there is no [[cpp_struct|struct]] type in python as in ==**C++**==.
### [[py_dictionary|Dictionary]]
It is a fundamental data structure that stores data in key-value pairs.
