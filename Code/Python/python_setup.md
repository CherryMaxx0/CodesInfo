## Installation process
First step is to go on this [Python Download Site](https://www.python.org/downloads/)
Which brings to this page looks like the image below:![[python_download.png]]
In here, you are suppose to click on the ==Python 3.14.7== or any other latest version that comes out will show up there.
>[!Warning]
>Not the ==Download Python install manager==, you don't need that thing.

___
When installing python, the window below will pop out
![Python_installer](https://docs.python.org/3/_images/win_installer.png)
You need to add python path to the path variable in the system or user specific in the pc. So tick the ==Add Python 3.8 to PATH== *(the image is for 3.8.0 version, this will vary as for the latest versions)*.
Then just continue default unless you want anything changes.
___
## [[Visual Studio code]] setup.
To setup [[py_.venv|Virtual Environment]] or set up with global environment, you need to go in search bar in vscode, or press `ctrl+P`, then use `>` then type or copy
```json
Python: Select Interpreter
```
Then choose ==Create Virtual environment== this will create `.venv` *(short form for Virtual Environment)* folder or Global tagged for global environment.
![[environment_setup.png]]
And the last thing to know is that the file extension for python, is `.py`
___
>[!Important]
>To may need to activate `.venv`, to do so, click here -> [[py_.venv|Virtual Environment]]

>[!Done]
>You are done with python setting up in your pc
